# Book catalog for the EN_JP language pair (English source text,
# Japanese explanations — see pipeline/internal/langpair): which
# Gutenberg books to ingest, and where the actual novel text starts/ends
# within them (everything outside that range - prefaces, illustration
# lists, colophons, "THE END" notices, and whatever else different
# editions surround the story with - is trimmed).
#
# Format: one entry per block, blocks separated by a single blank line.
# Each block is exactly 9 lines, in order:
#   1. the book's title, exactly as shown to the user
#   2. the author's name, exactly as shown to the user
#   3. the Project Gutenberg URL for the PLAIN TEXT edition specifically -
#      not the HTML, EPUB, or "-images" edition. On the book's Gutenberg
#      page (gutenberg.org/ebooks/<id>), that's the "Plain Text UTF-8"
#      download link; the URL usually ends in plain ".txt", e.g.
#      /cache/epub/<id>/pg<id>.txt or /files/<id>/<id>-0.txt. Clean (see
#      pipeline/internal/clean) looks for Gutenberg's own
#      "*** START/END OF ... PROJECT GUTENBERG EBOOK ***" markers, which
#      only exist in this edition - any other format will fail to parse.
#   4. the URL of an image to use as the book's cover - downloaded once
#      at processing time and stored in Postgres (book.book_image), not
#      hotlinked. A failed download is logged and skipped, not fatal -
#      the book still processes without a cover.
#   5. the first line of the actual novel content (verbatim, as it reads
#      after Clean's whitespace normalization - see pipeline/internal/clean)
#   6. the last line of the actual novel content (verbatim, same rules)
#   7. "Level=X" - the book's assigned reading level, X from 1 (easiest)
#      to 10 (hardest). Assigned manually per book, never derived by the
#      pipeline - see the README's Reading Levels table for what each
#      level means (name, TOEIC range, CEFR).
#   8. genre tags, comma-separated, 3 to 5 of them, the first of which
#      must be exactly "Fiction" or "Non-Fiction" (e.g. "Fiction,
#      Gothic, Horror") - the tag count bound is arbitrary, just to
#      keep every book's tag list roughly comparable. Assigned manually
#      per book, same as Level.
#   9. a short synopsis of the book, one line, written/sourced by hand -
#      not generated by the pipeline. Written in the book's own source
#      language (English, for this pair's entries), not the pair's
#      Japanese explanation language. If sourcing from somewhere rather
#      than writing it yourself, note that a synopsis someone else wrote
#      usually isn't public domain just because the novel itself is -
#      paraphrase rather than copy verbatim.
# A "# comment" line is ignored by the parser wherever it appears -
# useful for a section header or temporarily disabling an entry, but not
# needed per-entry anymore now that title/author are real fields.
#
# See the README's "Adding a Book to the Catalog" section for the full
# guide. Both the first-line and last-line strings must match exactly
# once in the cleaned text - if a book's chosen anchor isn't unique, pick
# a longer/more specific line.
